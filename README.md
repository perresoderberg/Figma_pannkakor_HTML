# Pannkakor Recipe Page

A simple responsive webpage that displays classic Swedish pancake recipes.

## Description

This project is a static HTML and CSS webpage designed to work on both desktop and mobile devices.
The layout adapts using responsive design techniques, and images are cropped differently depending on screen size.

## Technologies

- HTML5
- CSS3 (responsive design)

## Features

- Responsive layout (grid-based)
- Image cropping on mobile (center 50% visible)
- Clean and simple UI
