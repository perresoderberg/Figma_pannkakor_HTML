# Pannkakor Recipe Page

A simple responsive webpage that displays a classic Swedish pancake recipe.

## Description

This project is a static HTML and CSS webpage designed to work on both desktop and mobile devices.
The layout adapts using responsive design techniques, and images are cropped differently depending on screen size.

## Technologies

* HTML5
* CSS3 (responsive design with media queries)

## Features

* Responsive layout (grid-based)
* Image cropping on mobile (center 50% visible)
* Clean and simple UI

## Project Structure

```
index.html
styles.css
header_pannkakor.png
footer_pannkakor_1.png
footer_pannkakor_2.png
```

## How to Run

1. Download or clone the project
2. Open `index.html` in your browser

## Purpose

This project was created to practice:
* Responsive web design
* CSS layout techniques (Grid vs Flexbox)
